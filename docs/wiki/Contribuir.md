# Contribuir

Lee [CONTRIBUTING.md](https://github.com/crismoraga/Taller-IoT-v2-Raices-Digitales/blob/main/CONTRIBUTING.md) y [guía de desarrollo](https://github.com/crismoraga/Taller-IoT-v2-Raices-Digitales/blob/main/docs/DEVELOPMENT.md) antes de cambiar el código. Issues y pull requests deben explicar el comportamiento que se espera y cómo se comprobó.

Para una placa o un transporte nuevo, especifica MCU, perfil de compilación, bootloader, firma, velocidad, memoria, pines, prueba simulada y prueba física por separado. No afirmes que una placa está soportada por el mero hecho de reconocer su puerto.

Ejecuta `npm run check` y las pruebas de navegador pertinentes. Mantén documentos actualizados. No adjuntes secretos, configuración de Pico, bases de datos, capturas con identificadores de sesión ni herramientas generadas. No hay licencia de redistribución declarada en este repositorio; consulta al mantenedor antes de incorporar código externo con condiciones incompatibles.
